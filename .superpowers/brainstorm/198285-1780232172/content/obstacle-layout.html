2. 间距计算公式

障碍物间距 = 滚动速度 × 打字窗口时间

其中 打字窗口时间 = 字符数 × 0.25s + 0.8s（决策缓冲）

示例（Easy 模式，初始速度 200px/s）：
• 4字母词窗口 = 4 × 0.25 + 0.8 = 1.8s
• 最小间距 = 200 × 1.8 = 360px
• 实际间距 = 最小间距 × 1.3（安全系数）= 468px

3. 缺口大小设计

A

固定缺口高度

缺口始终为角色高度的 3 倍（约 120px），两个词分布在缺口的上1/3和下1/3处。简单稳定，但随着速度加快，难度只来自打字速度而非空间判断。

B

渐进缩小的缺口

初期缺口大（角色4倍高），后期逐渐缩小（最小到2.5倍）。两词间距也随之收窄，选择精度要求更高。速度+空间双重难度递增。

C

缺口高度随机波动

每次障碍物缺口在 [2.5x, 4x] 角色高度之间随机，两词位置随缺口变化。增加不可预测性，但可能导致不公平的随机死亡。

4. 单词放置规则

• 两个词竖直排列在缺口中央，上方词 = 高跳跃落点，下方词 = 低跳跃落点
• 词的水平位置 = 缺口水平位置（视觉绑定）
• 上词位置：缺口顶部往下 1/4 处
• 下词位置：缺口底部往上 1/4 处
• 玩家开始打字时，另一个词渐隐（减少干扰）
• 打完词后角色跳跃，已选词变亮消失，未选词渐隐
