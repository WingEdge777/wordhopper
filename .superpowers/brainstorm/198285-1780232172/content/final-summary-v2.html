Word Hopper — Final Considerations & Summary

Edge cases, polish details, and complete design recap

1. Edge Cases & Missing Considerations

Two words with same first letter

WordSpawner guarantees different first letters. If pool exhausted, retry until satisfied. Never show "leaf" + "love" together.

Player types while mid-air

Typing is always allowed. If player completes a word mid-jump, the current jump is overridden — new target height applied immediately. Physics recalculates velocity to reach new height.

Player types wrong letter mid-word

Word flashes red (200ms), progress resets to 0. Must retype from first letter. The other word remains available — player can switch by typing its first letter instead.

No input when obstacle arrives (skip)

Upper-only obstacle: player runs through gap, no jump, 0 bonus. Lower-only obstacle: player MUST jump or die. If you didn't type, you didn't jump. You die. This is the core tension.

Upper-only obstacle + skip = free pass?

Yes, intentional strategy: safe path (skip, 0 bonus) vs. risk path (type, +bonus). The score system makes skipping non-viable for high scores.

Multiple obstacle groups on screen

Yes at high speed. Only the NEAREST upcoming obstacle group accepts typing input. Farther groups are visible but dimmed. Player focuses on one at a time.

Window resize / mobile

Canvas is fixed 800×450, CSS-scaled to fit viewport. Mobile not supported in MVP — typing on touchscreen is a different game. Add later if needed.

Audio feedback

4 sounds: type-correct (soft tick), type-wrong (low buzz), jump (whoosh), death (thud). All short (<200ms). Optional — game is playable muted.

2. Complete Design Summary

Gameplay

  • Endless runner, character runs right, world scrolls left
  • One-hit death, instant restart
  • 3 difficulties: Easy (3-5), Medium (6-10), Hard (10+)
  • Two words per obstacle, first letters always differ
  • Words float in gap, bound to obstacle, scroll together
  • Position mapping: upper word = high jump, lower = low
  • Type correct → green, complete → jump
  • Type wrong → red flash, reset, can switch word
  • Skip typing → survive if gap allows, 0 bonus
  • Speed: 0-500m fixed → 500-1500m +1%/3 obstacles → 1500m+ +1%/obstacle, cap 2.5x

Scoring

  • Base: +1/tick (survival)
  • Word bonus: +10 × word_length × current_speed
  • Skip = safe but no bonus

Obstacles

  • 6 plant types: Cactus, Bramble, Mushroom, Venus Flytrap, Tree Stump, Hanging Vines
  • 3 layouts: upper+lower (70%), upper-only (15%), lower-only (15%)
  • Gap random: [2.5×, 4.5×] player height

Spacing

  • Min spacing = speed × (char_count × 0.25s + 0.8s) × 1.3
  • Obstacles + words appear simultaneously on the right

UI

  • HUD top-right: Score + Speed, grid layout, monospace
  • Menu: Title → difficulty → SPACE/START
  • Death: Score screen with stats → SPACE → menu
  • All English, words all lowercase

Tech Stack

Phaser 3 (Canvas) + TypeScript + Vite | Scenes: Boot → Menu → Game → Death | Systems: TypingSystem, WordSpawner, ObstacleSpawner, ScoreSystem, SpeedManager | Word lists: static JSON (easy: 1631, medium: 2756, hard: 1543) | Deploy: static site (any CDN) | Test: Vitest + Playwright
