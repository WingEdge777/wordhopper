# Word Hopper

[English](./README.md)

一款用于单词打字练习的跳跃游戏。

## 玩法

障碍物从右侧滚动而来，每个障碍物上显示一到两个单词。

1. **输入首字母** 选择一个单词
2. **继续输入** 完成整个单词
3. **按空格键** 跳过对应单词的间隙

输入错误需要重新选择。碰到障碍物则游戏结束。

随着通关数量增加，游戏速度会逐渐提升。三种难度对应不同词长：

- **Easy** — 3–5 个字符
- **Medium** — 6–8 个字符
- **Hard** — 8+ 个字符

## 开发
