# Word Hopper

[English](./README.md)

一款用于单词打字练习的跳跃游戏。

## 玩法

障碍物从右侧滚动而来，每个障碍物上显示一到两个单词。

1. **输入首字母** 选择一个单词
2. **继续输入** 完成整个单词
3. **按空格键** 跳过对应单词的间隙

输入错误需要重新选择。碰到障碍物则游戏结束。

完成单词后，屏幕上会出现一条**绿色时机线**，提示最佳起跳时刻。越靠近绿线起跳，落点越精准；距离绿线越近，闪光越亮。

随着通关数量增加，游戏速度会逐渐提升。四种难度对应不同词长与速度：

- **Chill** — 3–5 个字符，半速
- **Easy** — 3–5 个字符
- **Medium** — 6–8 个字符
- **Hard** — 8+ 个字符
